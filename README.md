# ReqPilot

**An AI-powered requirements analysis assistant for Business Analysts, Product Owners and Solution Designers.**

## Overview

ReqPilot helps transform unstructured business documents into clear, actionable requirements using Artificial Intelligence.

The application assists analysts by:

- Summarising business documents
- Extracting functional requirements
- Detecting ambiguities
- Suggesting clarification questions
- Generating user stories
- Producing acceptance criteria

This project demonstrates the design and implementation of an enterprise AI solution using modern software engineering practices.
